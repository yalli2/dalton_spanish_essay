# 스페인어 에세이 시험 대비 사이트 · 교육의 가치

국제학교 스페인어 에세이 시험을 준비하기 위한 인터랙티브 학습 사이트입니다.
교재 지문 세 개(**El «docente del año»**, **Savater 읽기 1.2**, **Savater: 교사와 권위**)를 바탕으로 합니다.

사이트 주소(GitHub Pages 활성화 후): https://yalli2.github.io/dalton_spanish_essay/

## 구성

| 메뉴 | 내용 |
| --- | --- |
| 시작하기 | 오늘 밤 학습 순서, 진행 상황, 에세이 핵심 전략 |
| 지문 1·2·3 | 단락별 영어·한글 번역 노트, 표현·문법 포인트, 번역 가리기(셀프 테스트) |
| 어휘 | 핵심 어휘 60개 (목록 / 플래시카드, 발음 듣기, 암기 체크) |
| 표현·문법 | 숙어·표현 29개, 문법 포인트 10개, 연결어 모음 |
| 에세이 10문제 | 문제별 의도·개요·유용한 표현·30분 타이머 작성 패드·모범답안(ES)과 한글 번역·자주 하는 실수 |
| 퀴즈 | 읽기 이해 12문제, 어휘 20문제, 표현 10문제 (해설 포함) |
| 작문 도우미 | 5단락 구조, 채점 기준 자가 점검, 제출 전 체크리스트, 자유 연습 공간 |

작성한 글, 암기 체크, 퀴즈 최고 점수는 사용하는 브라우저의 localStorage에만 저장됩니다.

## 파일 구조

```
index.html
css/style.css
js/app.js              화면과 기능
js/data_readings.js    지문별 번역 노트
js/data_vocab.js       어휘 · 표현 · 문법 · 연결어
js/data_essays.js      에세이 10문제 · 읽기 이해 퀴즈
```

빌드 과정 없이 정적 파일만으로 동작합니다. 로컬에서 보려면 `index.html`을 브라우저로 열면 됩니다.

## 내용 수정하기

문제나 어휘를 고치려면 `js/data_*.js` 파일의 배열을 수정하세요. 화면 코드는 건드리지 않아도 됩니다.

## 참고

번역 노트는 학습을 돕기 위한 풀이이며 교재 원문을 대신하지 않습니다. 예문과 모범답안은 학습용으로 새로 작성한 것입니다.
